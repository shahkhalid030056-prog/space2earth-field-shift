Space2Earth - Field Shift (Peshawar)
‎
‎Bilingual (English/Urdu) crop-rotation and climate-risk explorer for small farmers.
‎
‎**Challenge:** Field Shift - Adapting Farms with NASA Data - NASA Space Apps 2026
‎
‎**What it does:**
‎- Compares crop rotations (Wheat-Maize vs Wheat-Legume)
‎- Uses NASA POWER API - 25-year temp/rain trend, water balance, heat/frost risk
‎- Inputs: soil type, water availability, farmer priorities
‎- Features: what-if sliders, rank stability, Urdu/English + read-aloud, offline PWA, validation
‎
‎**Honest Limits:** Only NASA POWER integrated. SMAP, MODIS, GPM = future work via Earthdata. No false flood alerts.
‎
